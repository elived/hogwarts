# Hogwarts Houses App
A full-stack application that sorts users into Hogwarts houses.
Built with a frontend hosted on Vercel, a backend API on Render,
and a managed database.

## Live Application
- **Frontend:** https://hogwarts-ten-theta.vercel.app  
- **Backend API:** https://hogwarts-s5zi.onrender.com

## Tech Stack
**Frontend**
- React
- HTML / CSS
- TypeScript

**Backend**
- ASP .NET
- Entity Framework

**Database**
- PostgreSQL (hosted on Render)

## Database
PostgreSQL database hosted on Render.  
Database credentials are stored securely using environment variables.

## Getting Started Locally

### 1. Clone the repo
```bash
git clone https://github.com/your-username/hogwarts-houses-1.git
npm install
```
create a .env file:
```bash
DATABASE_URL=your_database_url_here
PORT=5000
```
Then run this in the terminal.
```bash
npm run dev
```
